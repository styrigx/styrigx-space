# 系列（series）

一组按顺序阅读的文章。frontmatter：

```yaml
series: ['Styrigx UI 鉴权规范'] # 系列名（数组，取第一个作为主系列；中英文版本各写各的名字）
seriesOrder: 2 # 可选：系列内篇序，正整数，从 1 开始
```

- 排序：同一系列先按 `seriesOrder` 升序，没写 `seriesOrder` 的排在后面，再按日期、文件名。
- 列表页「专题」页签最前面是系列卡（名称、篇数、按篇序的文章列表），然后是分类、标签；
  「首页」页签只放最新的一个系列卡。
- 文章页：属于系列的文章在标题下方有一个小块：系列名 · 第 n / N 篇 · 上一篇 / 下一篇。
  点系列名回到列表页 `#topics/series/<slug>`，滚到并高亮该系列卡。
- 系列的 n / N 只在同一语言里算（英文目前只有鉴权规范 2.0，所以英文是 第 1 / 1 篇）。

现有系列：`Styrigx UI 鉴权规范`（中文：密钥规范白皮书 v1.0 = 1，鉴权规范 2.0 = 2）/ `Styrigx UI Auth Spec`（英文：2.0 = 2）。
