I scoured the web for Muse (Meta's personal AI assistant) tips — X, Reddit, YouTube, V2EX, blogs, and reviews, in both English and Chinese. Deduplicated, verified where possible, organized into ten categories: 514 tips total, open-sourced on GitHub.

Repo: https://github.com/styrigx/muse-playbook

## Motivation

Muse's capabilities keep shifting, but the official docs only say what it *can* do — not how to use it well. The genuinely useful techniques live scattered across posts, comment threads, and videos: someone ran three months of email on it, someone else planned an entire trip. That knowledge deserves systematic collection.

## Collection Methods and Sources

- **Sources**: X, Reddit, YouTube, V2EX, independent blogs, product reviews — English and Chinese
- **Timing**: intensive collection in October 2026, with ongoing additions since
- **Inclusion bar**: must be expressible in one sentence and immediately actionable; pure commentary, ads, and copy-paste reposts don't make it

## Dedup and Verification Standards

- The same tip from Chinese and English sources is kept once, wording merged
- Entries marked as community reports are single-source experiences, not independently verified — try them on low-stakes tasks first
- Muse ships fast; some entries may go stale with new versions. The in-app interface is the final authority; stale entries welcome an Issue

## A Note on Credibility

This isn't an official manual — it's a collection of community experience. Every entry tries to note its source type; for anything touching permissions, payments, or account safety, check the official docs first. Content reflects versions as of collection (October 2026); Muse updates may move interfaces around — the in-app UI wins.

## Contributing

The repo takes PRs and Issues: what's missing, what's wrong, what's gone stale — file it. New entries should follow the existing format (one-line action + when it applies) and cite a source.
